Программа моделирует простую искусственную экосистему с использованием объектно-ориентированного подхода и логических агентов.

В искусственной среде размером 50×50 клеток находятся три типа агентов:

- растения;
- травоядные;
- хищники.

В каждой клетке может находиться только один агент. Каждый агент имеет собственное состояние и энергию.

Растения получают энергию за счёт роста. Травоядные питаются растениями, а хищники питаются травоядными. Если энергия животного становится равной или меньше нуля, агент погибает и удаляется из среды.

Травоядные и хищники обладают зрением 5×5 клеток, где сам агент находится в центре области наблюдения. Все перемещения выполняются только по четырём направлениям: вверх, вниз, влево и вправо.

## Логика агентов

### Травоядное

```text
ЕСЛИ видит хищника
    ТО убегает

ИНАЧЕ ЕСЛИ видит растение
    ТО движется к растению и питается им

ИНАЧЕ
    случайно выбирает направление движения
```

### Хищник

```text
ЕСЛИ видит травоядное
    ТО движется к нему и атакует

ИНАЧЕ
    случайно выбирает направление движения
```

### Растение

Растение увеличивает запас энергии на каждом шаге. При достижении фиксированного порога оно размножается и создаёт потомка в свободной соседней клетке.

После начальной случайной расстановки новые растения не появляются случайно по всему полю.

## Энергия и размножение

Параметры модели фиксированы во время работы симуляции.

Размножение не подстраивается под текущую численность популяций. Никаких специальных механизмов увеличения рождаемости при вымирании видов в программе нет.

При размножении родитель передаёт потомку часть своей энергии.


## Назначение основных классов

`Agent` — абстрактный базовый класс для всех агентов.

`Animal` — базовый класс для животных. Содержит общую механику движения, зрения и поиска целей.

`Herbivore` — логика поведения травоядного.

`Predator` — логика поведения хищника.

`Plant` — рост и размножение растений.

`Cell` — отдельная клетка среды.

`Position` — координаты агента.

`Environment` — управление клетками, агентами, движением, питанием, размножением и удалением погибших объектов.

`Simulation` — управление отдельными тактами симуляции.

`ConsoleApp` — предварительная консольная версия.

`GuiApp` и `SimulationPanel` — оконная версия на Swing.

`StatsApp` — автоматическая проверка устойчивости модели на случайных запусках.

`Config` — фиксированные параметры искусственной жизни.

## Запуск

Для запуска необходим JDK 21.

Сначала необходимо скомпилировать исходные файлы:

```bash
javac -encoding UTF-8 -d out src/alife/*.java
```

### Консольная версия

Запуск консольной версии:

```bash
java -Dfile.encoding=UTF-8 -cp out alife.Main console
```

Консольная версия показывает состояние первого шага, затем выполняет симуляцию и после завершения выводит последний шаг и итоговую статистику.

### Оконная версия

Запуск GUI:

```bash
java -Dfile.encoding=UTF-8 -cp out alife.Main
```

Оконная версия построена на Swing и отображает поле 50×50 клеток, состояние агентов, их энергию и текущую статистику.

В интерфейсе доступны кнопки запуска, паузы и выполнения одного шага.

### Автоматическая проверка

Проверка устойчивости выполняется классом:

```bash
java -Dfile.encoding=UTF-8 -cp out alife.StatsApp
```

Для каждого испытания используется новый случайный `seed`. Внутри одного запуска параметры модели не изменяются.
